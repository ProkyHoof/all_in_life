# 注释

注释是在程序指定位置添加的说明性信息。  
简单理解，就是对代码的一种解释。
 
注释分类  
单行注释：//注释信息  
多行注释：/*注释信息*/  
文档注释：/**注释信息*/
 
注意：  
注释内容不会参与编译和运行，仅仅对代码的解释说明。  
不管是单行注释还是多行注释，在书写的时候都不要嵌套。

# 数据类型

数据类型的分类  
基本数据类型和应用数据类型。
 
基本数据类型  
注意：  
如果定义long类型的变量，再数据值的后面需要加一个L作为后缀，L可以是大写也可以是小写，建议大写L。  
定义一个float类型变量的时候，数据值也需要加一个F作为后缀。
 
byte取值范围：-128 - 127。
 
整数和小数取值范围大小关系：  
double \> float \> long \> int \> short \> byte。  
**注意：**  
在Java中，byte类型和char类型是两种不同的数据类型。byte类型是一个8位的有符号整数，其范围为-128到127，占用一个字节。而char类型用于表示Unicode字符，是一个16位无符号整数，其范围为0到65535，占用两个字节。此外，char类型可以表示中文字符，而byte类型不能。
   

# 标识符

就是给类，方法，变量等起的名字。
 
标识符命名规则 - - - 硬性要求

- 由数字、字母、下划线（_）和美元符（$）组成。
- 不能以数字开头。
- 不能是关键字。
- 区分大小写。
 
标识符命名规则 - - - 软件建议  
小驼峰命名法：**方法、变量**  
规范1：标识符是一个单词的时候，全部小写。  
范例1：**name**  
规范2：标识符由多个单词组成的时候，第一个单词字母小写，其他单词首字母大写。  
范例2：**firstName**  
大驼峰命名法：**类名**  
规范1：标识符是一个单词的时候，首字母大写。  
范例1：**Student**  
规范2：标识符由多个单词组成的时候，每个单词的首字母大写。  
范例2：**GoodStudent**
 
# 键盘录入

介绍：Java帮我们写好了一个类叫Scanner，这个类就可以接受键盘输入的数字。  
**步骤一：导包** **--- Scanner****这个类在哪。**  
import java.util.Scanner; //导包的动作必须出现在类定义的上边。  
**步骤二：创建对象** **---** **表示我要开始用****Scanner****这个类了。**  
Scanner sc = new Scanner(System.in); //上边这个格式里面，只有sc是变量名，可以变，其他的都不允许变。  
**步骤三：接收数据** **---** **真正开始干活了。**  
int i = sc.nextInt(); //左边这个格式里面，只有i是变量名，可以变，其他的都不允许变。
