# 局域网（LAN）

概念：是一种覆盖范围较小的计算机网络，典型的使用场景是一个办公室、一个实验室、一栋楼甚至一个小型园区。  
特点：传输距离短、速度快、管理成单、成本低。  
局域网的关键功能：实现本地设备间的高速通信和资源共享。
 
# 以太网

概念：以太网是一种具体的局域网通信协议标准，定义了物理层和数据链路层的实现方式。  
起源与发展：最早由Xerox公司提出，后由DEC、Intel和Xerox联合推广形成DIX标准，之后成为IEEE 802.3标准的核心。  
功能：规定了MAC地址、帧结构、介质访问控制（如CSMA/CD机制）、传输速率（10Mbps - 100Mbps - 1Gbps及以上）等。
 
# 局域网VS以太网

局域网是应用范围（在一个有限区域内实现网络互联）。  
以太网是实现技术（怎么连、用什么协议、什么硬件）。  
除了以太网，还有其他局域网技术，比如早期的Token Ring、FDDI、ARCnet（但现在几乎都被以太网淘汰了）。

# 中继器（Repeater）

以太网中电缆具有最大的长度限制，也就是信号可以不失真传播的最大长度（粗：500米，细：185米），超过这个长度信号就不能正常传播了。  
中继器是一种信号增强装备，它能接收、放大并重传信号，多段由中继器连接起来的电缆段与一根单独电缆没有什么区别（队了由中继器引入的少量延迟）。
 
# 经典以太网

任意两个节点之间的距离不能超过2.5KM，并且任意两个收发器之间的路径不能跨越4个中继器。

# MAC地址

MAC地址又被称为硬件地址或物理地址，由48个比特位（6个字节）组成。  
MAC地址是全球唯一的。
 
单播地址：第一个字节最低位为0，表示目标是唯一的某个主机。  
组播地址：第一个字节最低位为1，表示目标是一组设备。  
广播地址：全F（FF-FF-FF-FF-FF-FF），也可以视为一种特殊的“组播”。
 
# 快速以太网

基本思想：保留原来的帧格式、接口和过程规则。  
将比特的传输速率从10Mb/s提升到100Mb/s，为了保证及时的检测冲突，只要将电缆的最大长度降低到1/10即可。

# 千兆以太网

当计算机被连接到一个集器而不是交换机时，就会使用半双工模式。
 
IEEE 802加入了两个特性，使得最大线缆长度增加到200m。  
特性一：载波扩充，本质就是让硬件在普通帧后增加一些填充位，将帧的长度从64个字节扩充到512字节（提升8倍），当用户发送46字节时，使用512字节传输，线路利用率只有9%。  
特性二：帧突发，允许发送方将多个待发送的帧的序列级联在一起，一次传输出去。如果帧突然小于512字节，则硬件再进行填充。

# 传统局域网的局限性

**广播风暴：**在一个大的局域网中，广播消息会不停地传输，影响宽带和网络性质，导致网络拥堵。  
**网络问题：**所有设备都在同一个广播域内，恶意设备可能会轻易地接受到其他设备的流量，存在安全隐患。  
**扩展问题：**随着网络规模的扩大，增加设备时必须调整物理布线，这使得扩展变得困难且成本高。
 
# 虚拟局域网（VLAN）

将物理局域网（LAN）划分为多个逻辑上的子网，每个子网叫做一个VLAN。VLAN通过逻辑隔离设备，保证设备之间的通信可以被有效管理，同时不会受到物理位置的限制。
 
# 虚拟局域网（VLAN）的目标

隔离广播流量：减少广播消息在网络中的传播范围。  
提高安全性：通过将不同部门或功能的设备划分到不同的VLAN，可以有效隔离它们之间的通信，降低攻击的风险。  
简化网络管理：即使设备不再同一设备，也可以通过VLAN分配到相应逻辑子网中。  
提高网络性能：划分VLAN可以减少网络中的冲突和广播流量，提高网络的整体效率。
 
# 如何划分虚拟局域网（VLAN）

最常用的方法是：根据交换机的端口来划分VLAN。  
以太网交换机的接口分为两类：access接口和trunk接口。
 
# access接口

接收帧后，根据预先分配好的VID值，给帧添加标签，然后判断交换机内其他端口分配到VID与帧中的标签VID是否一致，如果一致则转发，否则不转发。

# 广域网

广域网通常指覆盖范围很广的长距离网络，通常连接不同地区的城域网或者局域网，用来实现远距离通信。  
广域网中数据链路层使用的是点对点信道，主要使用的协议有PPP、LCP、NCP。
 
# PPP协议

PPP（Point to Point Protocol）协议：用于点对点的数据链路中，为通信双方建立点对点的连接。PPP协议只支持点对点全双式链路的数据链路层协议。

1. 将IP数据报封装到串行链路中，这部分信息长度小于MTU（0 - 1500）。
2. 链路控制协议（Link Control Protocol，LCP）：用于建立、配置和测试链路的连接。
3. 网络控制协议（Network Control Protocol，NCP）：用于支持不同网络层协议（如IPv4、IPv6）的配置和协商。
 
# PPP协议数据帧格式

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E6%95%B0%E6%8D%AE%E9%93%BE%E8%B7%AF%E5%B1%82%EF%BC%88%E4%BB%A5%E5%A4%AA%E7%BD%91_%E8%99%9A%E6%8B%9F%E5%B1%80%E5%9F%9F%E7%BD%91_ppp_%E6%97%A0%E7%BA%BF%E7%BD%91%E8%A1%A5%E5%85%85%EF%BC%89%20image%203982a0e040672d2a.png)

F：标志字段，固定为0x7E，表示帧的开始和结束。  
A：地址字段，通常为0xFF，广播地址。  
C：控制字段，通常为0x03，表示无特定控制。  
协议：指示该帧的协议类型，如IP。  
数据：封装网络层的数据。  
帧校验序列：用于错误检测，确保数据完整性。
 
# PPP数据帧的传输流程

发起连接：PPP连接通过链路控制协议（LCP）进行协商，双方交换链路参数并通过认证。  
数据传输：PPP数据帧根据网络层协议（如IPv4）进行封装，并通过点对点链路传输。  
链路管理：连接过程中，LCP会对链路状态进行监控，并在必要时进行链路恢复。  
断开连接：通信完成后，PPP通过LCP断开连接。
