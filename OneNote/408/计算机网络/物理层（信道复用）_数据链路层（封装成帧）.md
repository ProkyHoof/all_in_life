# 信道复用

信道复用（Channel Multiplexing）是指在有限的物理信道资源上，通过不同方式让多个信号共享同一个信道，以提高资源利用率和通信效率。对物理信道进行复用主要有三种方式：频率、时间和编码。  
常见的信道复用技术有：**频分复用、时分复用、码分复用**，此外还有一种称为波分复用，本质上是频分复用的光学形式。
 
# 频分复用

频分复用（FDM，Frequency Division Multiplexing）：将可用带宽划分多个频段，每个信号占据不同的频段进行传输。（收音机）
 
# 时分复用

时分复用（TDM，Time Division Multiplexing）：多个信号按照时间片轮流占用整个信道，每个信号在不同的时间间隔内传输。（对讲机）
 
# 码分复用

码分多路复用（CDM，Code Division Multiplexing）：又称码分多址CDMA，所有用户在相同的频率和时间共享信道，但每个用户使用不同的编码来区分信号。
 
# 波分复用

波分多路复用（WDM，Wavelength Division Multiplexing）：类似FDM，但用于光纤通信，每个信号用不同的波长的光进行传输。
 
# 码分复用-码片序列

码片（chip）：在CDMA中，一比特会被再细分成多个码片，码片是比比特更短的单位。每个比特由多个码片组成。通常情况下，一个比特被分为64或128个码片。  
计算机网络中每一个节点会被分配一个码片序列：

# 物理层接口特性

机械特性：指明接口所用接线器的形状和尺寸、引脚数目和排列、固定和锁定装置。  
电气特性：指明在接口电缆各条线路上出现的电压范围、传输速率、距离限制等。  
功能特性：指明某一线路上出现的某一电平的电压表示何种意义（数据线、控制线）。  
过程特性：指明对于不同功能的各种可能出现的时间顺序。
 
# 数据链路层（第二层）

数据链路层的核心人物是在物理层提供的比特流基础上，提供可靠的数据传输，并确保数据能正确地从一个设备发送到另一个设备。  
向网络层提供一个定义良好的服务接口。  
将数据报封装成帧/从比特流中解析帧。  
错误检测和纠正。  
调节数据流。  
介质访问控制。
 
# 帧

在数据链路层，数据以“帧（Frame）”的形式进行传输，每一帧通常包含以下三部分：  
帧头（Header）：包含地址信息（原地址、目的地址）、帧类型、控制信息等。  
数据（payload）：承认来自网络层的数据报文（通常是IP数据报）  
帧尾（Trailer）：通常包含校验和用于检测数据传输错误。

# 分装成帧-字节计数法

在帧的头部添加一个字段，指明该帧的字节数。  
优点：简单易实现，占用的额外开销少。  
缺点：如果计数字段的数据**被传输错误，**会导致**数据同步错误**，接收端可能会错误地解析数据。
 
# 分装成帧-字符填充法

使用特殊字符（如SOH代表帧起始，EOT代表帧结束），并在数据部分中避免特殊字符的冲突。  
SOH（Start of Header） EOT（End of Transmission）

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E7%89%A9%E7%90%86%E5%B1%82%EF%BC%88%E4%BF%A1%E9%81%93%E5%A4%8D%E7%94%A8%EF%BC%89_%E6%95%B0%E6%8D%AE%E9%93%BE%E8%B7%AF%E5%B1%82%EF%BC%88%E5%B0%81%E8%A3%85%E6%88%90%E5%B8%A7%EF%BC%89%20image%206710281d4b787f5b.png)

如果数据中包含SOH或EOT，则用ESC（转义字符）来填充，避免误判。  
优点：解决了字节计数法的同步问题，适用于字符流。  
缺点：增加了额外的转义字符，可能会占用带宽。
 
# 分装成帧-比特填充法

使用特定的比特模式作为帧的起始和终止标志，并在数据部分中避免比特模式的冲突。  
数据中如果出现连续5个1，则自动填充0。

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E7%89%A9%E7%90%86%E5%B1%82%EF%BC%88%E4%BF%A1%E9%81%93%E5%A4%8D%E7%94%A8%EF%BC%89_%E6%95%B0%E6%8D%AE%E9%93%BE%E8%B7%AF%E5%B1%82%EF%BC%88%E5%B0%81%E8%A3%85%E6%88%90%E5%B8%A7%EF%BC%89%20image%2018a00d3ced492e2f.png)

优点：适用于任何比特流，不局限于字符编码（比字符填充更通用）。  
缺点：需要额外的比特填充，稍微增加了传输开销。
 
# 封装成帧-物理层编码法

数据报封装成帧后，直接在物理层使用信号的变化来标识帧的起始和结束，而不是依赖特定的比特模式。  
优点：不需要填充比特，不会增加额外的开销。  
缺点：依赖物理层的编码方式，不适用于所有链路层协议。
