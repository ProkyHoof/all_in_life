# 基本概念

服务是指一层向它上一层提供的一组原语（操作）
 
# TCP/IP参考模型

TCP/IP模型最早实现之一是作为Berkerley Unix的一部分，尤其是学术界都把TCP/IP看成是Unix的一部分。

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E7%BD%91%E7%BB%9C%E4%BD%93%E7%B3%BB%E7%BB%93%E6%9E%84%E7%89%A9%E7%90%86%E5%B1%82%EF%BC%88%E4%BC%A0%E8%BE%93%E4%BB%8B%E8%B4%A8%E3%80%81%E7%BC%96%E7%A0%81%EF%BC%89%20image%201b6da734a1da0db4.png)  

# TCP/IP参考模型的问题

TCP/IP模型没有明确区分服务、接口和协议的概念。  
TCP/IP模型不通用，不合格描述TCP/IP之外的协议栈，比如蓝牙。  
TCP/IP模型中的链路层并不是通常意义的一层，它只是一个接口。接口和层的区别非常重要，应该区分。  
TCP/IP模型并没有区分物理层和数据链路层。  
早期自主实现的协议已经被广泛使用，导致其他的协议难以取代。

# 数据链路层

数据链路层使用物理层提供的服务在通信信道上发送和接收比特  
向网络层提供一个定义良好的服务接口  
将比特序列组织成帧  
错误检测和纠正

# 网络层

将数据传输到目标地址  
目标地址可以是多个网络通过路由器连接而成的某个地址  
该层负责寻址和路由选择
 
# 传输层

传输层的目标是向应用层上的进程提供高效的、可靠的和性价比合理的数据传输服务
 
# 会话层

负责建立和断开通信连接
 
# 表示层

主要负责数据格式的转换，将应用处理的信息转换为适合网络传输的格式，或者将下一层的数据转换为上层能够处理的格式。
 
# 应用层

为应用程序提供服务并规定应用程序中通信相关的细节。  

# 双绞线（Twisted Pair）

双绞线是由两根相互绝缘的铜线组成，铜线直径大约为1nm 。两根线绞在一起之后，它们产生的波会相互抵消，从而能显著降低电线的辐射。  
双绞线既可以用于传输模拟信息，也可以用于传输数字信息。
 
双绞线分为外部**有屏蔽的双绞线**和**没有屏蔽的双绞线**两类。  
**有屏蔽的双绞线（****Shielded Twisred Pair****，****STP****）**：使用铝箔包裹在外部，减少外部电气噪声干扰的线缆，一般用于工地等噪声干扰较多的地方。  
**非屏蔽的双绞线（****Unshielded Twisted Pair****，****UTP****）**：不带任何屏蔽的双绞线，一般在家庭和办公室。

# 光纤（Fiber）

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E7%BD%91%E7%BB%9C%E4%BD%93%E7%B3%BB%E7%BB%93%E6%9E%84%E7%89%A9%E7%90%86%E5%B1%82%EF%BC%88%E4%BC%A0%E8%BE%93%E4%BB%8B%E8%B4%A8%E3%80%81%E7%BC%96%E7%A0%81%EF%BC%89%20image%20d143fcc3c1cf6deb.png)  

光纤传输系统有三部分组成，分别是光源、传输介质和检测器。
 
光纤有**单模光纤**和**多模光纤**两种，二者传输距离不同。  
**单模光纤：**直径小于10um，光信号进入光纤后，沿着直线传播而不会发生反射。通信衰减少，通信容量大，广泛用于长距离传输，价格昂贵。  
**多模光纤：**直径大于50um，根据光发生全反射的特性，只要当入射角大于临界值时，此时的光都会在光纤内部发生全反射。此时许多不同的光以不同的角度反射向前传播，可以说每一束光都有不同的模式。适用于近距离传输。
 
# 同轴电缆（coaxial cable）

同轴电缆：比非屏蔽双绞线有更好的屏蔽特性和更大的宽带。过去用于电话系统长距离传输，现在已经被光纤取代。目前广泛应用于有线电视和城域网，有些地方用于互联网接入。  
常用的同轴电缆：  
50欧姆电缆，用于数字传输。  
75欧姆电缆，用于模拟传输和有线电视传输。

# 无线传输

常见的无线传输有无线电波、微波、红外线、激光等。  
无线电波：具有较强的穿透能力，可以实现长距离传输。应用领域有手机通信、无线局域网、广播。  
微波：比无线电波频率更高的电磁波。应用领域有卫星通信。  
红外线：是不可见光的一种，通常用于近距离遥控。  
激光：点对点的通信技术，容易受天气影响。

# 编码-归零编码

归零编码（RZ编码，Return-to-Zero Code）：正电平代表逻辑1，负电平代表逻辑0，每传输完一位数据，信号返回到零电平。
