# 基本概念

ISP（Internet Service Provider）：互联网服务提供商  
节点（node）：计算机、交换机、路由器等构成网络的硬件都可以称为网络中的节点  
主机（host）：通过网络为其它机器提供服务的计算机，也称服务器  
客户端（client）：指从主机处获得服务的计算机，也称为终端

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C%E6%A6%82%E8%BF%B0%20image%203c739c304be3dfb6.png)  

# ISP层次互联

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C%E6%A6%82%E8%BF%B0%20image%2089de9a822f87a89e.png)  

报文（message）：网络中交换与传输的数据单元。  
分组（packet）：为了从源端系统向目的端系统发送一个报文，源端将长报文划分为较小的数据块，称为分组。

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C%E6%A6%82%E8%BF%B0%20image%20006ad6ca27712678.png)

比特（bit）：用小写字母b表示，1b表示一个二进制位，0或1。  
字节（byte）：用大写字母B表示，1B表示一个字节。

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C%E6%A6%82%E8%BF%B0%20image%209dcb7848a0eb15b7.png)  

传输速率：每秒钟传输多少个比特（bit/s，b/s，bps bit per second）。

![](OneNote/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C%E6%A6%82%E8%BF%B0%20image%2033c6f11085949aa9.png)

计算机网络中，带宽用来表示网络中某信道传送数据的能力，网络带宽表示单位时间内网络中的某信道所能通过的“最高数据率”，带宽单位：bit/s，b/s。
 
# 网络分类-分布范围

个域网（Personal Area Network PAN）  
局域网（Local Area Network LAN）  
城域网（Metropolitan Area Network MAN）  
广域网（Wide Area Network WAN）
 
# 网络分类-其他

按网络的使用者分类：公用网、专用网  
按网络的交换方式分类：电路交换、报文交换、分组交换  
按网络的拓补结构分类：星型、总线型、环型、树型、网状型  
按网络的传输介质分类：双绞线、同轴电缆、光纤、无线  
按网络的用途分类：教育、科研、商业、企业、政府
 
# OSI参考模型

基于国际标准化组织（International Standards Organization ISO）1983年开发的提案提出了OSI（Open System Interconnection）参考模型，并在1995年修订。
