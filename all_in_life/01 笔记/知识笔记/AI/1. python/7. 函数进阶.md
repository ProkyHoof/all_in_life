# 重新认识函数  
1. 函数也是对象。
2. 函数可以动态添加属性。
3. 函数可以赋值给变量。
4. 函数也可以作为参数

``` python
# 函数也是对象
a1 = 100  # int 类的实例对象
a2 = "Hello"  # str 类的实例对象
a3 = [10, 20, 30]  # list 的实例对象

def welcome():
	print("你好")  # welcome 函数是 function 类的实例对象

print(type(welcome))  # <class 'function'>

# 函数可以动态添加属性
welcome.desc = "这是一个打招呼的函数"
welcome.version = 1.0
print(welcome.desc)  # 这是一个打招呼的函数
print(welcome.version)  # 1.0

# 函数可以赋值给变量
say_hello = welcome
say_hello()  # 你好
print(say_hello.desc)  # 这是一个打招呼的函数
```
