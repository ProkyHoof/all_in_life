# 栈的基本概念
## 栈的定义
**栈（Stack）** 是**只允许在一端进行插入或删除操作**的**线性表**。
重要术语：栈顶、栈底、空栈。
	栈顶：允许插入和删除的一端。
	栈底：不允许插入和删除一端。
特定：**后进先出**。Last In First Out
## 栈的基本操作
`InitStack(&S)`：**初始化**栈。构造一个空栈`S`，**分配内存空间**。
`DestroyStack(&L)`：**销毁**栈。销毁并**释放**栈`S`所占用的**内存空间**。
`Push(&S, x)`：**进栈**，若栈`S`未满，则将`x`加入使之成为新**栈顶**。
`Pop(&S, &S)`：**出栈**，若栈`S`非空，则弹出**栈顶**元素，并用`x`返回。
`GetTop(S, &x)`：**读栈顶元素**。若栈`S`非空，则用`x`返回栈顶元素。
其他常用操作：
`StackEmpty(S)`：判断一个栈`S`是否为空。若`S`为空，则返回`true`，否则返回`false`。
## 栈的常考题型
$n$ 个不同元素进栈，出栈元素不同排列的个数为$\dfrac{1}{n + 1}C_{2n}^n$ 。 
上述公式称为卡特兰（Catalan）数，可采用数学归纳法证明（不要求掌握）。

## 进栈操作

``` C
#define MaxSize 10  //  定义栈中元素的最大个数
typedef struct {
	ElemType data[MaxSize];  //  静态数组存放栈中元素
	int top;  //  栈顶指针
} SqStack;

//  新元素入栈
bool Push(SqStack &S, ElemType x) {
	if (S.top == MaxSize - 1) {  //  栈满，报错
		return false;
	}
	S.top = S.top + 1;  //  指针先加1
	S.data[S.top] = x;  //  新元素入账
	return true;
}
```

##  出栈操作

``` C
#define MaxSize 10  //  定义栈中元素的最大个数
typedef struct {
	ElemType data[MaxSize];  //  静态数组存放栈中元素
	int top;  //  栈顶指针
} SqStack;

//  出栈操作
bool Pop(SqStack &S, &x) {
	if (S.top == -1) {
		return false;  //  栈空，报错
	}
	x = S.data[S.top];  //  栈顶元素先出栈
	S.top = S.top - 1;  //  指针再减1
}
```

## 读栈顶元素操作

``` C
#define MaxSize 10  //  定义栈中元素的最大个数
typedef struct {
	ElemType data[MaxSize];  //  静态数组存放栈中元素
	int top;  //  栈顶指针
} SqStack;

bool GetTop(SqStock S, ElemType &x) {
	if (S.top == -1) {  //  栈空，报错
		return false;
	}
	x = S.data[S.top];  //  记录栈顶元素
	return true;
}
```

## 共享栈
共享栈：两个栈共享一片空间
``` C
#define MaxSize 10  //  定义栈中元素的最大个数
typedef struct {
	ElemType data[MaxSize];  //  静态数组存放栈中元素
	int top0;  //  0号栈栈顶指针
	int top1;  //  1号栈栈顶指针
} ShStack;

//  初始化栈
void InitStack(ShStock &S) {
	S.top0 = 1;  //  初始化栈指针
	S.top1 = MaxSize;  //  
}
```

**栈满的条件**：`top0 + 1 = top1`。
