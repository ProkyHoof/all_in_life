# 指针与函数
***
## 间接引用操作符*
间接引用操作符 * 返回指针变量的指向地址的值。通常把这个操作叫做“解引用指针”。英文叫做 dereferencing a pointer。
```C
int a = 5;
int *p = &a;
printf("%d\n, *p");
*p = 100;
printf("%d\n, a");
```
设计一个函数，传入两个int函数，并交换这两个参数的值。
```C
void swap(int *a, int *b) {
	int temp;
	temp = a;
	a = b;
	b = temp;
	printf("a = %d, b = %d\n", a, b);
}

int main(int argcm char const *argv[]) {
	int m = 5;
	int n = 10;
	swap(&m, &n);
	printf("m = %d, n = %d\n", m, n);
	return 0;
}
```
在C语言中，指针与数组的关系十分密切。通过数组下标能完成的操作都可以通过指针完成。一般来说，用指针编写的程序比用数组下标编写的程序执行速度快。
```C
int a[] = {1, 2, 3, 4}
int *p;
p = a;
printf("%p\n", a);
printf("%p\n", p);
printf("%d", *p);
```
>在指针加上一个整数，实际上加的是这个整数和指针数据类型对应字节数的乘积。

## 各数据类型字节数

| 有符号数   | 无符号数           | 32位 | 64位 |
| ------ | -------------- | --- | --- |
| char   | unsigned char  | 1   | 1   |
| short  | unsigned short | 2   | 2   |
| int    | unsigned int   | 4   | 4   |
| long   | unsigned long  | 4   | 8   |
| float  |                | 4   | 8   |
| double |                | 8   | 8   |
