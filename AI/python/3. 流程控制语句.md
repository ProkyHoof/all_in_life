# 单分支  

``` python
age = 18
if age >= 18:
	print("你是成年人") 
```

# 双分支  

``` python
age = 18
if age >= 18:
	print("你是成年人")
else:
	print("你不是成年人")
```

# 多分支  

``` python
age = 18
if age <= 10:
	print("你是幼儿")
elif age <= 18:
	print("你是青少年")
elif age <= 30:
	print("你是青年")
elif age <= 50:
	print("你是中年")
elif age <= 60:
	print("你是中年人")
else:
	print("你是老年")
```

> 分支之间是互斥的。
