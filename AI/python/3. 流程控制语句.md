# 单分支  

``` python
age = 18
if age >= 18:
	print("你是成年人") 
```

# 双分支  

``` python
age = 18
if age >= 18:
	print("你是成年人")
else:
	print("你不是成年人")
```

# 多分支  

``` python
age = 18
if age <= 10:
	print("你是幼儿")
elif age <= 18:
	print("你是青少年")
elif age <= 30:
	print("你是青年")
elif age <= 50:
	print("你是中年")
elif age <= 60:
	print("你是中年人")
else:
	print("你是老年")
```

> 分支之间是互斥的。  

# 嵌套分支  
e.g. 为长跑俱乐部，设计一个马拉松比赛报名审核程序，具体规则如下：  
1. 参赛年龄必须是：18~45 岁之间。
2. 参赛前必须提交体验报告，否则不能比赛。
3. 比赛结束后，根据会员的等级，领取不同礼物。
	1. 1 级会员礼物为：纪念 T 恤。
	2. 2 级会员礼物为：专业跑鞋。
	3. 3 级会员礼物为：运动耳机。

``` python
age = int(input("请输入你的年龄"))
is_submit_report = int(input("是否提交体检报告（1 表示提交，0 表示未提交）"))
grade = int(input("请输入你的会员等级，等级分别是1，2，3"))
if age >= 18 and age <= 45:  # 简写：18 <= age <= 45
	if is_submit_report == 1:
		if grade == 1:
			print("纪念 T 恤一件")
		elif grade == 2:
			print("专业跑鞋一双")
		elif grade == 3:
			print("运动耳机一副")
	else:
		print("未提交体检报告不能参赛")
else:
	print("不符合年纪要求")
```
