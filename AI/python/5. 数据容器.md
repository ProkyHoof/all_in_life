# 数据容器  
数据容器：一种能存放多个数据的数据类型。  
数据容器可以更高效的管理成批的数据，且便于存储、访问。  
1. 容器中的每一个数据，又称：每一个元素。
2. Python 中有很多种数据容器。

不同的数据容器，有不同的特点，和不同的语法，但都有一个共性，就是都可以存储多个元素。  
# 列表（list）  
## 定义列表  
`[元素0, 元素1, 元素2, 元素3, ...]`  
定义空列表：列表中的数据，后期会通过特定写法填充。  

``` python
# 定义有内容的变量
list1 = [34, 56, 21, 56, 11]
list2 = ["合肥", "猪脚", "你好"]
list3 = ["23", "猪脚", True, None]
list4 = ["23", "猪脚", True, None, [100, 200, 300]]

# 定义空列表（列表中的数据，后期会通过特定写法填充）
list5 = []
list6 = list()

print(list1)
print(list2)
print(list3)
print(list4)
```

## 下标（索引值）  
下标（索引值）：列表中元素的位置编号。
