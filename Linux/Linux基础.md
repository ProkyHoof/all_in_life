
# 操作系统概述
***
操作系统（Operating System, OS）是管理计算机硬件与软件资源的计算机程序，是用户和计算机硬件之间的桥梁。
## 常见的操作系统
**PC端**
	Windows
	Linux
	macOS
**移动端**
	Android
	iOS
	鸿蒙（HarmonyOS）
# 系统简介与发行版
***
## Linux的诞生
**创始人**：Linus Torvalds
**诞生时间**：1991年
## Linux的内核（Kemel）
**内核的作用**：管理和调度所有硬件资源，是硬件与软件之间的桥梁。
**内核的特性**：完全免费开源。
## Linux发行版（Distribution）
**发行版**：由个人或组织将Linux内核与系统级应用程序打包、形成的完整、可直接安装使用的操作系统。
**发行版的构成**：内核（Linux Kemel） + 系统软件（GNU工具链、桌面环境） + 应用软件（浏览器、办公套件等）。
**发行版的特点**：由于开源特性，任何人都可以制作发行版，以满足服务器、桌面、移动设备等不同场景的需求。
> 发行版将内核与应用软件打包，提供开箱即用的完整系统，满足从服务器到个人桌面的各种需求。

## 主流的Linux发行版
**CentOS**：企业级服务器领域的佼佼者，稳定可靠。
**Ubuntu**：桌面用户的首先之一，易用性强，社区活跃。
**Debian**：Ubuntu的上游发行版，以其严谨和自由著称。
**Fedora**：由Red Hat赞助，更新较快，新技术的试验田。
**openSUSE**：以强大的包管理系统和YaST配置工具闻名。
