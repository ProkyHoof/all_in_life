
# 操作系统概述
***
操作系统（Operating System, OS）是管理计算机硬件与软件资源的计算机程序，是用户和计算机硬件之间的桥梁。
## 常见的操作系统
**PC端**
	Windows
	Linux
	macOS
**移动端**
	Android
	iOS
	鸿蒙（HarmonyOS）
# 系统简介与发行版
***
## Linux的诞生
**创始人**：Linus Torvalds
**诞生时间**：1991年
## Linux的内核（Kemel）
**内核的作用**：管理和调度所有硬件资源，是硬件与软件之间的桥梁。
**内核的特性**：完全免费开源。
