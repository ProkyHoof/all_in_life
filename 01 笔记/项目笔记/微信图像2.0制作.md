# 1 灵感来源  
本项目的来源是想制作一个比较简洁的微信图像，主要是黑白配色，核心设计还是围绕 ProkyHoof 设计，于是我想我应该做一个成长的系列，也就是说应该设计成一个成长主题的微信图像。或许这让我意识到 ProkyHoof 这个 LOGO 不存在于意识创造上，而是要我去正式它的未来，也就是我的未来，要有一个明确的规划，。所以这次的微信图像采用是启蒙和眺望的设计。  
人人往往在发呆的时候，思维开拓性才是最强的，我认为这时的人不是真正意识上的放空，而是对未来的幻想和憧憬，于是，我采用了探索未知后陷入的空洞为主要动作，设计了初期的懵懂，后续可能还会有悲欢离合吧，所以欢迎来到 ProkyHoof 的世界吧，从现在正式开始。  

# 2 项目目标
- 设计一个小男孩。（可以理解现实中的我）
- 设计一个头盔。（可以理解成想成为的我，即未来的我 ProkyHoof）
- 设计一个探索思考的场景，但不脱离现实。（现在的我和未来的我之间的关系，到底还有多远）

# 3 设计思路
1. 人物的塑造。
	这一定是一个小男孩，一个懵懂无知，好奇心的小男孩，为了贴合程序员的刻板印象吧，因为小时候的我就是因为带帽子就是这类职业的形象，所以在设计之初我给他设计了一个帽子，当然我带了眼镜，所以他也必须带上眼镜。
2. 头盔的设计。
	为什么一定要有头盔：因为从 ProkyHoof 诞生那一刻起，除了英文字母和中文的译名，还有一个最初的标志性形象。如下图所示：
	
	![](../../03%20附件/attachments/项目附件/微信图像2.0制作/项目笔记_20260923_1.png)

	初代的 LOGO 一共有三个设计，勇士、ZJ、ProkyHoof。而勇士最核心的特征就是头盔，象征着无畏，象征着向前。
	这次的设计中处理将初代 LOGO 的头盔绘制出以外，我还在头盔中添加了“幸运头环”的设计，俗话说得好，运气也是实力的一部分。
3. 场景的设计。
	场景有三部分组成：小男孩、头盔、桌面。我认为他们都有不同的意向。
	- 小男孩：是现实中的我，是刚刚起步的我，是无知的我，是过去矮小的我，是那个渺小的我，但是我一直保持着对未来的期望。
	- 头盔：是 ProkyHoof 的具象化，是对未来的具象化，是在未来我需要学习的东西：无畏，勇气，幸运，守护（或许是守卫现在的自己，就像我需要力量去守护现在弱小的自己一样）。
	- 桌面：是童年的象征，是发展平台的象征，是需要面对的现实。
	小男孩想爬上桌子去带上头盔。猪脚想借助已有的平台去成为 ProkyHoof。
4. 彩蛋的设计。
	在小男孩的帽子上有着一个“❤️”的补丁。为什么是❤️的补丁，可能就是：世界以痛吻我，我却报之以歌吧😄。
