# 1 FastAPI 简介  
FastAPI 是一个现代、高性能的 Python Web 框架，用于构建 API。它基于 Starlette（异步 Web 框架）和 Pydantic（数据验证库），结合了异步编程和类型提示，坚固开发效率与运行性能。  
文档：[FastAPI - FastAPI](https://fastapi.tiangolo.com/zh/)  
## 1.1 FastAPI 的核心优势  
**高性能**：  
- FastAPI 基于异步 I/O，性能接近 Node.js 和 GO。
- 使用 Uvicorn（ASGI 服务器），支持高并发请求。
- 性能对比（基于 TechEmpower 等基准测试，简化为每秒请求数）：
	- FastAPI：~3000 请求/秒（异步，轻量）。
	- Flask：~1000 请求/秒（同步，受 WSGI 限制）。
	- Django:~800 请求/秒（同步，ORM 和中间件开销较大）。

**类型提示升级开发效率**：  
- FastAPI 使用 Python 类型提示（通过 Pydantic）进行进行数据验证，减少手动校验代码。
- 类型提示使代码更易读，IDE（如 VSCode）提供自动补全和错误提示。
- 示例：定义一个带类型提示的 API 端点：

``` python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
	name: str
	price: float
	is_offer: bool = None

@app.post("/items/")
async def create_item(item: Item):
	return item
```

> 提示  
> 上述代码自动验证请求体中的 `name` (字符串)、`price`（浮点数）和 `is_offer`（布尔值，可选），无需手动解析 JSON。  

**自动生成 API 文档**：  
- FastAPI 内置 Swagger UI 和 ReDoc，自动生成交互式 API 文档。
- 开发者只需编写代码，文档即自动生成，减少维护成本。

**异步支持**：  
- 支持 `async/await` 语法，适合高并发场景（如实时聊天、流处理）。
- 比传统同步框架（如 Flask）更适合现代 Web 应用。

## 1.2 CGI/WSGI/ASGI  

![](../../../../03%20附件/attachments/知识附件/Python/2.%20FastAPI/2.%20FastAPI_20261004_1.png)

- CGI 是最早的通用接口，解决服务器与动态内容生成程序的通信问题，但性能低下。
- WSGI 针对 Python 生态优化，取代 CGI 成为 Python Web 开发的主流标准，专注于同步 Web 应用。
- ASGI 是 WSGI 的升级，适应异步编程和现代 Web 需求（如 WebSocket、HTTP/2），兼容 WSGI 应用。

# 2 FastAPI 环境搭建  
## 2.1 创建虚拟环境  
虚拟环境隔离项目依赖，避免全局环境冲突，以下使用 conda 工具：  
1. 创建虚拟环境：

``` python
python -m venv .venv  # .venv 是虚拟环境名
```

2. 激活虚拟环境：

``` python
.venv\Scripts\activate
```

3. 退出虚拟环境：

``` python
deactivate
```

## 2.2 安装 FastAPI 及其依赖  
1. 在虚拟环境中安装 FastAPI：

``` python
pip install "fastapi[standard]"
```

	指定版本安装：

``` python
pip install fastapi==0.115.12
pip install uvicorn==0.34.2
```

# 3 第一个 API 与启动项目  

``` python
from fastapi import FastAPI
import uvicorn

app = FastAPI()

@app.get("/")
def read_root():
    return {"Hello": "World"}

if __name__ == "__main__":
    uvicorn.run("main01:app", host="127.0.0.1", port=8000, reload=True)
    # uvicorn file_name:object --reload
```

## 3.1 启动项目
1. 运行 Python 脚本。

``` python
uvicorn.run("main01:app", host="127.0.0.1", port=8000, reload=True)
uvicorn.run(app, host="127.0.0.1", port=8000, reload=True, debug=True)
```

	代码中要用服务器启动代码。
2. 服务器启动项目。

``` python
uvicorn file_name:object --reload
```

3. 调试命令。

``` python
fastapi dev filename.py
```

# 4 用 AI 生成 API 接口  
## 4.1 使用 AI 生成 FastAPI 代码  
AI 工具可以通过自然语言提示生成代码。我们将模拟使用 AI 生成一个简单的 FastAPI 应用。  
**提示示例**：  
向 AI 提示以下提示：  

``` python
# 编写一个 FastAPI 的 Helloworld 程序

# 请为我生成一个 FastAPI 应用程序，功能；返回欢迎消息
```

以下生成的代码  

``` python
# main.py

# 从 fastapi 包中导入 FastAPI 类，它是整个应用的核心
from fastapi import FastAPI

# 创建一个 FastAPI 应用实例
# 参数 title、description、version 会显示在自动生成的 API 文档中
app = FastAPI(
    title="Hello World API",
    description="一个最简单的 FastAPI 示例程序",
    version="1.0.0",
)


# 使用装饰器 @app.get("/") 定义一个 GET 请求的路由
# 当用户访问根路径 "/" 时，就会触发下面这个函数
@app.get("/")
def read_root():
    """
    根路由处理函数
    返回值会自动被 FastAPI 转换为 JSON 格式响应给客户端
    """
    return {"message": "Hello, World!"}


# 定义一个带路径参数的路由
# {name} 是路径参数，FastAPI 会自动把它传给函数参数 name
@app.get("/hello/{name}")
def say_hello(name: str, times: int = 1):
    """
    带参数的问候接口
    - name: 路径参数，类型为字符串
    - times: 查询参数(例如 /hello/Tom?times=3)，默认值为 1
    """
    # 参数类型注解(str、int)会自动进行类型校验
    # 若传入的 times 不是整数，FastAPI 会自动返回 422 错误
    return {"message": f"Hello, {name}! " * times}
```

> 注意事项  
> AI 生成的代码可能存在小错误（如缺少字段约束），需手动检查。  

AI 的生成的问题  
1. AI 生成代码的局限性
	- 缺乏上下文理解：AI 生成的代码可能符合语法，但未必适配实际业务逻辑（如身份验证流程、数据库设计）。
	- 难以维护与调试：若学生只会“复制粘贴”，遇到错误或需求变更时将束手无策。
	- 部署与运维盲区：AI 通常不涉及服务器配置、性能优化、监控等生产环境构建环节。

2. 核心能力的不可替代性
	- 架构设计思维：如何划分模块，设计 REST API、管理依赖关系，需系统性训练。
	- 调试与问题定位：理解上下文机制、请求生命周期，才能快速排查异常。
	- 安全与性能意识：防止 SQL 注入，XSS 攻击或优化数据库查询，需人工介入设计。

# 5 FastAPI 路径参数  
FastAPI 支持使用 Python 字符串格式化语法声明路径参数（变量）：  

``` python
from fastapi import FastAPI

app = FastAPI()

# @app.get("/args/1")
# def get_args_1():
#     return {"message": "id1"}

@app.get("/args/{id}")
def get_args_2(id: int):
    return {"message": f"id{id}"}

if __name__ == "__main__":
    import uvicorn
    uvicorn.run("main03:app", host="0.0.0.0", port=8000, reload=True)
```

> 函数的顺序就是路由的顺序。  

# 6 FastAPI 查找参数  
声明的参数不是路径参数时，路径操作函数会把该参数自动解释为查找参数。  
查找字符串是键值对的集合，这些键值对位于 URL 的 `?` 之后，以 `&` 分隔。  
例如：`http://127.0.0.1:8000/items/?page=1&limit=10`
