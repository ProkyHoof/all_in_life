# HTML
定义：超文本标记语言  
1. html文件是浏览器负责解析和展示  
2. html文件是纯文本文件，普通编辑工具都可以编辑  
1. html文件的根文件<html></html>  
2. html根标签下有两个一级子标签<head></head> <body></body>  
head头标签：定义那些不直接展示在页面主体上，但是又很重要的内容（字符集、CSS引入、JS引入）  
body体标签：定义要展示到页面主体的标签

# BOM编程
BOM是Browser Object Model的简写，即浏览器对象模型  
BOM由一系列对象组成，是访问、控制、修改浏览器的属性和方法（通过window对象及属性的一系列方法控制浏览器行为的一种编程）  
BOM没有统一的标准（每种客户端都可以自定标准）  
BOM编程是将浏览器窗口的各个组成部分抽象成各个对象，通过各个对象的API操作组件行为的一种编程。  
# DOM编程
简单来说：DOM（Document Object Model）编程就是使用document对象的API完成对网页HTML文档进行动态修改，以实现网页数据和样式动态变化效果的编程。  
逻辑结构是一种树型结构的对象  
dom树上的结点类型  
node结点  
1 元素结点 element 标签  
2 属性结点 attribute 属性  
3 文本结点 text 双标签中间的文字

# HTTP协议
HTTP超文本传输协议（Hyper Text transfer protocol），是一个属于应用层的面向对象的协议。它是一种详细规定了浏览器和万维网服务器之间互相通信的规则。客户端发送给服务器的称为“请求报文”，服务器发送给客户端的称为“响应报文”。  
1 客户端和服务端交互的方式  
请求 永远都是客户端向服务端发送  
响应 永远都是服务端向客户端返回  
2 客户端和服务端交互数据的格式  
请求时发送的数据 称之为请求报文  
响应时返回的数据 称之为响应报文  
报文规定的格式：行、头、报文主体  
3 http 长连接和短连接问题  
http 应用层协议  
tcp 传输层协议  
ip 网络层协议  
## 请求报文格式
1 请求首行（请求行）：GET/POST 资源路径?参数 HTTP/1.1  
2 请求头信息（请求头）  
3 空行  
4 请求体：POST请求才有请求体
