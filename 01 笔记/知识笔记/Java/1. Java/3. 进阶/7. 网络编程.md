# 1 网络编程
## 1.1 什么是网络编程
在网络通信协议下，不同计算机上运行的程序，进行的数据传输。  
应用场景：即时通信、网络对战、金融证券、国际贸易、邮件等等。  
不管是什么场景，都是计算机跟计算机之间通过网络进行数据传输。  
## 1.2 BS 架构和 CS 架构
### 1.2.1 BS 架构的优缺点
1. 不需要开发客户端，只需要页面 + 服务端。  
2. 用户不需要下载，打开浏览器就能使用。  
3. 如果应用过大，用户体验受到影响。  

### 1.2.2 CS 架构的优缺点
1. 画面可以做的非常精美，用户体验好。  
2. 需要开发客户端，也需要开发服务端。  

## 1.3 网络编程三要素
IP：设备在网络中的地址，是唯一的标识。  
端口号：应用程序在设备中唯一的标识。  
协议：数据在网络中传输的规则，常见的协议有 UDP、TCP、http、https、ftp。  
### 1.3.1 IP
全称：Internet Protocol，是互联网协议地址，也称 IP 地址。  
是分配给上网设备的数字标签。  
通俗理解：上网设备在网络中的地址，是唯一的。  
常见的 IP 分类为：IPv4、IPv6。  
IPv4：  
- 全称：Internet Protocol version 4，互联网通信协议第四版。  
- 采用 32 位地址长度，分成 4 组。  

IPv6：  
- 全称：Internet Protocol version 6，互联网通信协议第六版。  
- 由于互联网的蓬勃发展，IP 地址的需求量愈来愈大，而 IPv4 的模式下 IP 的总数是有限的。  
- 采用 128 位地址长度，分成 8 组。  

### 1.3.2 IPv4 的地址分类形式
1. 公网地址（万维网使用）和私有地址（局域网使用）。  
2. 192.168. 开头的就是私有地址，范围即为 192.168.0.0 - 192.168.255.255，专门为组织机构内部使用，以此节省 IP。  

### 1.3.3 特殊 IP 地址
127.0.0.1，也可以是 localhost：是回送地址也称本地回环地址，也称本机 IP，永远只会寻找当前所在本机。  
### 1.3.4 常用的 CMD 命令
1. ipconfig：查看本机 IP 地址。  
2. ping：检查网络是否连通。  

### 1.3.5 InetAddress 的使用

```java
InetAddress address = InetAddress.getByName("192.168.1.18");
String name = address.getHostName();
String ip = address.getHostAddress();
```

### 1.3.6 端口号
应用程序在设备中唯一的标识。  
端口号：由两个字节表示的整数，取值范围：0 - 65535。  
其中 0 - 1023 之间的端口号用于一些知名的网络服务或者应用。  

> 注意：一个端口号只能被一个应用程序使用。  

### 1.3.7 协议
计算机网络中，连接和通信的规则被称为网络通信协议。  
1. OSI 参考模型：世界互联协议标准，全球通信规范，单模型过于理想化，未能在因特网上进行广泛推广。  
2. TCP/IP 参考模型（或 TCP/IP 协议）：事实上的国际标准。  

![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/网络编程%20image%203d00af38d34af390.png)  

UDP 协议：  
1. 用户数据报协议（User Datagram Protocol）。  
2. UDP 是面向无连接通信协议。  

速度快，有大小限制，一次最多发送 64K，数据不安全，易丢失数据。  
TCP 协议：  
1. 传输控制协议 TCP（Transmission Control Protocol）。  
2. TCP 协议是面向连接的通信协议。  

速度慢，没有大小限制，数据安全。  
## 1.4 UDP 通信程序
### 1.4.1 发送数据
1. 创建发送端的 DatagramSocket 对象。  
2. 数据打包（DatagramPacket）。  
3. 发送数据。  
4. 释放资源。  

```java
DatagramSocket ds = new DatagramSocket();
String str = "你好";
byte[] bytes = str.getBytes();
InetAddress address = InetAddress.getByName("127.0.0.1");
int port = 10086;
DatagramPacket dp = new DatagramPacket(bytes, bytes.length, address, port);
ds.send(dp);
ds.close();
```

### 1.4.2 接收数据
1. 创建接收端的 DatagramSocket 对象。  
2. 接收打包好的数据。  
3. 解析数据包。  
4. 释放资源。  

```java
DatagramSocket ds = new DatagramSocket(10086);
byte[] bytes = new byte[1024];
DatagramPacket dp = new DatagramPacket(bytes, bytes.length);
ds.receive(dp);
byte[] data = dp.getData();
int len = dp.getLength();
InetAddress address = dp.getAddress();
int port = dp.getPort();
ds.close();
```

### 1.4.3 UDP 的三种通信方式
1. 单播：以前的代码就是单播。  
2. 组播：组播地址 224.0.0.0 - 239.255.255.255，其中 224.0.0.0 - 224.0.0.255 为预留的组播地址。  
3. 广播：广播地址 255.255.255.255。  

组播发送端：  

```java
MulticastSocket ms = new MulticastSocket();
String s = "nihao nihao";
byte[] bytes = s.getBytes();
InetAddress address = InetAddress.getByName("224.0.0.1");
int port = 10000;
DatagramPacket datagramPacket = new DatagramPacket(bytes, bytes.length, address, port);
ms.send(datagramPacket);
ms.close();
```

组播接收端：  

```java
MulticastSocket ms = new MulticastSocket(10000);
InetAddress address = InetAddress.getByName("224.0.0.1");
byte[] bytes = new byte[1024];
DatagramPacket dp = new DatagramPacket(bytes, bytes.length);
ms.receive(dp);
byte[] data = dp.getData();
int len = dp.getLength();
String ip = dp.getAddress().getHostAddress();
String name = dp.getAddress().getHostName();
ms.close();
```

## 1.5 TCP 通信程序
TCP 通信协议是一种可靠的网络协议，它在通信的两端建立一个 Socket 对象。  
通信之前要保证连接已经建立。  
通过 Socket 产生 IO 流来进行网络通信。  
客户端：  
1. 创建客户端的 Socket 对象与指定服务端连接。  
2. 获取输出流，写数据。  
3. 释放资源。  

服务端：  
1. 创建服务器端的 ServerSocket 对象。  
2. 监听客户端连接，返回一个 Socket 对象。  
3. 获取输入流，读数据，并把数据显示在控制台。  
4. 释放资源。  

客户端代码：  

```java
Socket socket = new Socket("127.0.0.1", 10000);
OutputStream os = socket.getOutputStream();
os.write("nihao nihao".getBytes());
os.close();
socket.close();
```

服务端代码：  

```java
ServerSocket ss = new ServerSocket(10000);
Socket socket = ss.accept();
InputStream is = socket.getInputStream();
int b;
while ((b = is.read()) != -1) {
    System.out.print((char) b);
}
socket.close();
ss.close();
```

解决中文乱码问题：  

```java
InputStreamReader isr = new InputStreamReader(is);
```
