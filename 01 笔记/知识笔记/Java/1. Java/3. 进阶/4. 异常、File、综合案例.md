# 1 异常
## 1.1 异常的分类
异常：异常就是代表程序出现的问题。  
1. ArrayIndexOutOfBoundsException：数组索引越界异常。  
2. ArithmeticException：算术异常。  
![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/异常、File、综合案例%20image%208f3b5621884b5251.png)  
Error：代表的系统级别错误（属于严重问题）。  
系统一旦出现问题，sun 公司会把这些错误封装成 Error 对象。  
Error 是给 sun 公司自己用的，不是给我们程序员用的。  
因此我们开发人员不用管它。  
Exception：叫作异常，代表程序可能出现的问题。  
我们通常会用 Exception 以及它的子类来封装程序出现的问题。  
![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/异常、File、综合案例%20image%20b19edc448c0e81cf.png)  
运行时异常：RuntimeException 及其子类，编译阶段不会出现异常提醒，运行时出现的异常（如：数组索引越界异常）（在编译阶段是不需要处理的，是代码运行时出现的异常）。  
编译时异常：编译阶段就会出现异常提醒的（如：日期解析异常）（在编译阶段，必须要手动处理，否则代码会报错）。  
```java
Java 文件 --javac 命令--> 字节码文件 --java 命令--> 运行结果
```
javac 命令出现异常为编译时异常。  
java 命令出现异常为运行时异常。  
编译阶段：Java 不会运行代码，只会检查语法是否错误，或者会做一些性能的优化。  
运行阶段：代码出错而导致程序出错的问题。  
## 1.2 异常的作用
作用一：异常是用来查询 bug 的关键参考信息。  
作用二：异常可以作为方法内部的一种特殊返回值，以便通知调用者底层的执行情况。  
```java
throw new RuntimeException();
```
## 1.3 异常的处理方式
### 1.3.1 JVM 默认的处理方式
1. 把异常的名称、异常原因及异常出现的位置等信息输出在了控制台。  
2. 程序停止执行，异常下面的代码不会再执行了。  
### 1.3.2 自己处理（捕获异常）
```java
try {
    可能出现异常的代码;
} catch (异常类名 变量名) {
    异常的处理代码;
}
```
```java
try {
    System.out.println(arr[10]);
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("索引越界了");
}
```
> 注意一：如果 try 中没有遇到问题，会把 try 里面所有的代码执行完毕，不会执行 catch 里面的代码。只有当 try 中出现了异常才会执行 catch 里面的代码。  
> 注意二：如果 try 中可能遇到多个问题，那么需要写多个 catch 与之对应。如果我们要捕获多个异常，这些异常中如果存在父子关系的话，那么父类一定要写在下面。  
> 在 JDK7 之后，我们可以在 catch 中同时捕捉多个异常，中间用"|"进行分隔。表示如果出现 A 异常或者 B 异常的话，采取同一种处理方案。  
> 注意三：如果 try 中遇到的问题没有被捕获，那么相当于最终还会交给虚拟机进行处理。  
> 注意四：如果 try 中遇到问题。那么 try 中下面的代码就不会运行，直接跳转到对应的 catch 当中，执行 catch 里面的语句体，但是如果没有对应 catch 与之匹配，那么还是交给虚拟机进行处理。

### 1.3.3 抛出异常
throws 注意：写在方法定义处，表示声明一个异常。  
告诉调用者，使用本方法可能会有哪些异常。  
throw 注意：写在方法内，结束方法。  
手动抛出异常对象，交给调用者。  
方法中下面的代码不再执行了。  
- 编译时异常：必须要写。  
- 运行时异常：可以不写。  
```java
public void 方法() throws 异常类名1, 异常类名2 ... {
    ...
}
```
```java
public void 方法() {
    throw new NullPointerException();
}
```

## 1.5 自定义异常
意义：就是为了让控制台的报错信息更加的见名知意。  
1. 定义异常类。  
2. 写继承关系（RuntimeException 或 Exception）。  
3. 空参构造（Alt + insert）。  
4. 带参构造。  
示例：  
```java
public class NameFormatException extends RuntimeException {
    //空参构造
    public NameFormatException() {}

    //带参构造

    }
}
```
# 2 File
## 2.1 File 概述
- File 对象就表示一个路径，可以是文件的路径，也可以是文件夹的路径。  
- 这个路径可以是存在的，也允许是不存在的。  
![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/异常、File、综合案例%20image%20316184c8e99dfaf1.png)  
```java
String str = "C:\\Desktop\\a.txt";
File f1 = new File(str);
System.out.println(f1);
```
父级路径：C:\Desktop  
子级路径：a.txt  
```java
String parent = "C:\\Desktop";
String child = "a.txt";
File f2 = new File(parent, child);
System.out.println(f2);
```
```java
File parent = new File("C:\\Desktop");
String child = "a.txt";
File f3 = new File(parent, child);
System.out.println(f3);
```
> 注意：  
> 绝对路径是带盘符的。  
> 相对路径是不带盘符的，默认到当前项目下去找。

## 2.3 File 的常见成员方法（获取并遍历）
![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/异常、File、综合案例%20image%20391ce8f9261d1e20.png)  
```java
File f = new File("D:\\aaa");
File[] files = f.listFiles();
for (File file : files) {
    System.out.println(file);
}
```
作用：获取 aaa 文件夹里面的所有内容，把所有的内容放到数组中返回。  
file 依次表示 aaa 文件夹里面的每一个文件或者文件夹。  
![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/异常、File、综合案例%20image%200ab97388961f44f5.png)  
- 当调用者 File 表示的路径不存在时，返回 null。  
- 当调用者 File 表示的路径是文件时，返回 null。  
- 当调用者 File 表示的路径是一个空文件夹时，返回一个长度为 0 的数组。  
- 当调用者 File 表示的路径是一个有内容的文件夹时，将里面所有文件和文件夹的路径放在 File 数组中返回。  
- 当调用者 File 表示的路径是一个有隐藏文件的文件夹时，将里面所有文件和文件夹的路径放在 File 数组中返回，包括隐藏文件。  
- 当调用者 File 表示的路径是需要权限才能访问的文件夹时，返回 null。  
```java
File[] arr = File.listRoots();
System.out.println(Arrays.toString(arr));
```
listRoots 获取系统中所有的盘符。  
```java
File f1 = new File("D:\\aaa");
String[] arr2 = f1.list();
for (String s : arr2) {
    System.out.println(s);
}
```
list() 获取当前路径下所有内容（仅仅能获取名字）。  
```java
File f2 = new File("D:\\aaa");
String[] arr3 = f2.list(new FilenameFilter() {
    @Override
    public boolean accept(File dir, String name) {
        File src = new File(dir, name);
        return src.isFile() && name.endsWith(".txt");
    }
});
System.out.println(Arrays.toString(arr3));
```
list(FilenameFilter filter) 利用文件名过滤器获取当前该路径下所有内容。  
accept 方法的形参，依次表示 aaa 文件夹里面每一个文件或者文件夹的路径。  
参数一：父级路径。  
参数二：子级路径。  
返回值：如果返回值为 true，就表示当前路径保留。  
如果返回值为 false，就表示当前路径舍弃不要。  
```java
File f = new File("D:\\aaa");
File[] arr = f.listFiles();
for (File file : arr) {
    if (file.isFile() && file.getName().endsWith(".txt")) {
        System.out.println(file);
    }
}
```

## 2.4 File 的常见成员方法（创建、删除）
![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/异常、File、综合案例%20image%2067e9214a00645baf.png)  
createNewFile 创建文件：  
```java
File f1 = new File("D:\\aaa\\a.txt");
boolean b = f1.createNewFile();
System.out.println(b);
```
细节一：如果当前路径表示的文件是不存在的，则创建成功，方法返回 true。  
如果当前路径表示的文件是存在的，则创建不成功，方法返回 false。  
细节二：如果父级路径是不存在的，那么方法会有异常 IOException。  
细节三：createNewFile 方法创建的一定是文件，如果路径中不包含后缀名，则创建一个没有后缀的文件。  
mkdir 创建单级文件夹：  
```java
File f2 = new File("D:\\aaa\\bbb");
boolean b = f2.mkdir();
System.out.println(b);
```
细节一：windows 当中路径是唯一的，如果当前路径已经存在，则创建失败，返回 false。  
细节二：mkdir 方法只能创建单级文件夹，无法创建多级文件夹。  
mkdirs 创建多级文件夹：  
```java
File f3 = new File("D:\\aaa\\aaa\\bbb\\ccc");
boolean b = f3.mkdirs();
System.out.println(b);
```
细节：既可以创建单级的，又可以创建多级的文件夹。  
delete 删除：  
```java
File f1 = new File("D:\\aaa\\a.txt");
boolean b = f1.delete();
System.out.println(b);
```
细节：如果删除的是文件，则直接删除，不走回收站。  
如果删除的是空文件夹，则直接删除，不走回收站。  
如果删除的是有内容的文件夹，则删除失败。

```java
public static void delete(File src) {
    File[] files = src.listFiles();
    for (File file : files) {
        if (file.isFile()) {

        } else {
            delete(file);
        }
    }
```

练习五：统计文件夹的大小。  
![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/异常、File、综合案例%20image%204cf8324f9208e740.png)

```java
public static void main(String[] args) {
    File file = new File("D:\\aaa\\src");
    long len = getLen(file);
    System.out.println(len);
}

public static long getLen(File src) {
    long len = 0;
    File[] files = src.listFiles();
    for (File file : files) {
        if (file.isFile()) {
            len = len + file.length();
        } else {
            len = len + getLen(file);
        }
    }
    return len;
}
```

练习六：统计每种类型的文件个数。  
![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/异常、File、综合案例%20image%2096b82e4350c1dc19.png)  
```java
public static void main(String[] args) {
    File file = new File("D:\\aaa\\src");
    HashMap<String, Integer> hm = getCount(file);
    System.out.println(hm);
}

public static HashMap<String, Integer> getCount(File src) {
    HashMap<String, Integer> hm = new HashMap<>();
    File[] files = src.listFiles();
    for (File file : files) {
        if (file.isFile()) {
            String[] arr = file.getName().split("\\.");
            if (arr.length >= 2) {
                String endName = arr[arr.length - 1];
                if (hm.containsKey(endName)) {
                    int count = hm.get(endName);
                    count++;
                    hm.put(endName, count);
                } else {
                    hm.put(endName, 1);
                }
            }
        } else {
            HashMap<String, Integer> sonMap = getCount(file);
            Set<Map.Entry<String, Integer>> entries = sonMap.entrySet();
            for (Map.Entry<String, Integer> entry : entries) {
                String key = entry.getKey();
                int value = entry.getValue();
                if (hm.containsKey(key)) {
                    int count = hm.get(key);
                    count = count + value;
                    hm.put(key, count);
                } else {
                    hm.put(key, value);
                }
            }
        }
    }
    return hm;
}
```
