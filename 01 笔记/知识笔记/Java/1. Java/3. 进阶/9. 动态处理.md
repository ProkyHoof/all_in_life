# 1 动态处理（动态代理）
特点：无侵入式的给代码增加额外的功能。  
代理里面就是对象要被代理的方法。  
通过接口保证，后面的对象和代理需要实现同一个接口。  
接口中就是被代理的所有方法。  

![](../../../../../03%20附件/attachments/知识附件/Java/1.%20Java/进阶/动态处理%20image%207e1b514934a199f1.png)  

## 1.1 JDK 动态代理的实现步骤
1. 定义接口：接口中声明被代理的所有方法。  
2. 编写真实类：实现接口，实现具体业务逻辑。  
3. 创建代理：通过 Proxy.newProxyInstance 方法，传入类加载器、接口数组和 InvocationHandler 调用处理器。  
4. 在 InvocationHandler 的 invoke 方法中，对目标方法进行增强，再调用真实对象的方法。  

```java
public interface Star {
    String sing(String name);
}

public class BigStar implements Star {
    private String name;

    public BigStar(String name) {
        this.name = name;
    }

    @Override
    public String sing(String name) {
        System.out.println(this.name + "正在唱" + name);
        return "谢谢大家";
    }
}
```

```java
import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;

public class Test {
    public static void main(String[] args) {
        BigStar bigStar = new BigStar("刘德华");
        //生成代理对象
        Star proxy = (Star) Proxy.newProxyInstance(
            Star.class.getClassLoader(),
            new Class[]{Star.class},
            new InvocationHandler() {
                @Override
                public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
                    System.out.println("代理前置增强：收钱");
                    Object result = method.invoke(bigStar, args);
                    System.out.println("代理后置增强：宣传");
                    return result;
                }
            }
        );
        String msg = proxy.sing("忘情水");
        System.out.println(msg);
    }
}
```
