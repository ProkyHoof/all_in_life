# 1 注释

注释是在程序指定位置添加的说明性信息。  
简单理解，就是对代码的一种解释。  

注释分类：  
- 单行注释：`//注释信息`  
- 多行注释：`/*注释信息*/`  
- 文档注释：`/**注释信息*/`（用于生成 API 文档）  

> 注意：  
> 1. 注释内容不会参与编译和运行，仅仅对代码的解释说明。  
> 2. 不管是单行注释还是多行注释，在书写的时候都不要嵌套。  
> 3. 单行注释只能注释一行内容；多行注释可以注释多行，但不能嵌套。  
> 4. 文档注释通常用于类、方法等上面，可以提取生成帮助文档。

# 2 关键字

定义：被 Java 赋予了特定涵义的英文单词。  

关键字的特点：  
- 关键字的字母全部小写。  
- 常用的代码编辑器（如 IDEA、Eclipse）针对关键字有特殊的颜色标记，非常直观。  
- 常见的关键字有：`class`、`public`、`static`、`void`、`int`、`double`、`if`、`else`、`for`、`while` 等。  

`class` 关键字：用于创建一个类，后面跟随类名。类是 Java 最基本的组成单元，每个 Java 源文件对应一个类。

# 4 制表符

制表符 `\t` 的作用：在打印的时候，把前面字符串的长度补齐到 8，或者 8 的整数倍。最少补 1 个空格，最多补 8 个空格。  

例如：`System.out.println("姓名\t年龄");` 中的 `\t` 会自动对齐后面的内容。  

换行符 `\n`：在打印的时候，换行显示后面的内容。例如：`System.out.println("第一行\n第二行");` 会分两行输出。

# 5 null 空字符

`null` 是 Java 中的空值，表示一个变量没有指向任何对象。  

注意：  
- `null` 只能用于引用数据类型（如字符串、数组、自定义类等），不能用于基本数据类型。  
- 对 `null` 对象调用方法或访问属性会抛出 `NullPointerException`（空指针异常）。

# 6 变量

变量是内存中一块存储数据的空间。  
变量的定义格式：`数据类型 变量名 = 数据值;`  

变量的使用方法：  

**1. 输出打印**

```java
int a = 10;
System.out.println(a); // 输出 10
```

**2. 参加计算**

```java
int a = 10;
int b = 20;
System.out.println(a + b); // 输出 30
```

**3. 修改记录的值**

```java
int a = 10;
a = 20;
System.out.println(a); // 输出 20
```

变量的注意事项：  
- 一个变量只能存一个值。  
- 变量名不允许重复定义（同一作用域内）。  
- 一条语句可以定义多个变量（如 `int a = 10, b = 20;`），但不推荐。  
- 变量在使用之前一定要进行赋值，否则编译报错。  
- 变量有其作用范围（从定义处到所在代码块结束），超出范围不可使用。

# 7 计算机的存储规则

在计算机中，任意数据都是以二进制的形式来存储的。  

## 7.1 文本编码

使用汉字编码表：GBK 编码（中文国标编码）和 Unicode 编码（Unicode 字符集，UTF-8/UTF-16 是其编码方式）。  

## 7.2 图片数据

屏幕分辨率：  
- 2K 屏：1920 x 1080 / 1998 x 1080 / 2048 x 1080 / 2048 x 858  
- 4K 屏：3840 x 2160 / 3996 x 2160 / 4096 x 2160 / 4096 x 1716  

黑白图：1 代表"白"，0 代表"黑"。  
灰度图：0 表示"黑"，255 表示"白"，中间值表示不同程度的灰色。  

彩色图：  
- 光学三原色：红（R）、绿（G）、蓝（B）。  
- 通过每一个像素点中的 RGB 三原色来存储颜色。  
- 每个颜色分量范围为 0 ~ 255，即 (0, 0, 0) 为黑色，(255, 255, 255) 为白色。  

## 7.3 声音数据

对声音的波形图进行采样再存储。采样频率越高、量化位数越大，声音还原越真实，但文件也越大。

# 8 数据类型

Java 是强类型语言，所有变量都必须先定义后才能使用。  

## 8.1 数据类型的分类

Java 的数据类型分为两大类：  
- **基本数据类型**（8 种）  
- **引用数据类型**（类、接口、数组等）  

## 8.2 基本数据类型

基本数据类型共 8 种，分为四类：  

**整数类型**：  
- `byte`：1 字节，取值范围 -128 ~ 127  
- `short`：2 字节，取值范围 -32768 ~ 32767  
- `int`：4 字节，取值范围 -2^31 ~ 2^31-1（-2147483648 ~ 2147483647）  
- `long`：8 字节，取值范围 -2^63 ~ 2^63-1（-9223372036854775808 ~ 9223372036854775807）  

> 注意：定义 long 类型的变量，在数据值的后面需要加一个 L 作为后缀（L 可大写可小写，建议大写）。  

**浮点类型**：  
- `float`：4 字节，单精度浮点数  
- `double`：8 字节，双精度浮点数  

> 注意：定义 float 类型变量的时候，数据值需要加一个 F 作为后缀。  

**字符类型**：  
- `char`：2 字节，表示一个 Unicode 字符，范围 0 ~ 65535  

**布尔类型**：  
- `boolean`：1 字节，只有 `true` 和 `false` 两个值  

**整数和小数取值范围大小关系**：  
`double` > `float` > `long` > `int` > `short` > `byte`  

> 注意：  
> 1. byte 类型和 char 类型是两种不同的数据类型。byte 是 8 位有符号整数（-128 ~ 127），char 是 16 位无符号整数（0 ~ 65535）。  
> 2. char 类型可以表示中文字符，而 byte 类型不能。  
> 3. 默认情况下，Java 中小数字面量（如 3.14）是 double 类型。  
> 4. float 和 double 存储的是近似值，浮点数运算可能存在精度丢失（如 0.1 + 0.2 的结果不等于 0.3）。  

## 8.3 数据类型转换

**自动类型转换（隐式转换）**：  
当取值范围小的数据类型与取值范围大的数据类型进行运算时，系统会自动将小范围类型转换为大范围类型。  

```java
int a = 10;
double b = a; // int 自动转换为 double，b = 10.0
```

**强制类型转换（显式转换）**：  
当需要将大范围类型赋值给小范围类型时，需要手动进行强制类型转换，但可能导致精度丢失或溢出。  

```java
double d = 3.9;
int i = (int) d; // 强制转换，i = 3（小数部分被截断）
```

> 注意：强制类型转换可能导致数据精度丢失，使用需谨慎。

# 9 标识符

标识符就是给类、方法、变量等起的名字。  

## 9.1 硬性要求（必须遵守）

- 由数字、字母、下划线 `_` 和美元符 `$` 组成。  
- 不能以数字开头。  
- 不能是关键字。  
- 区分大小写（`name` 和 `Name` 是两个不同的标识符）。  

## 9.2 软件建议（命名规范）

**小驼峰命名法**（用于方法、变量）：  
- 规范 1：标识符是一个单词时，全部小写。  
  - 范例：`name`  
- 规范 2：标识符由多个单词组成时，第一个单词字母小写，其他单词首字母大写。  
  - 范例：`firstName`、`studentAge`  

**大驼峰命名法**（用于类名）：  
- 规范 1：标识符是一个单词时，首字母大写。  
  - 范例：`Student`  
- 规范 2：标识符由多个单词组成时，每个单词的首字母大写。  
  - 范例：`GoodStudent`、`HelloWorld`  

# 10 键盘录入

Java 提供了 `Scanner` 类用于接收键盘输入。  

**步骤一：导包** — Scanner 这个类在 `java.util` 包中。

```java
import java.util.Scanner; // 导包动作必须出现在类定义的上边
```

**步骤二：创建对象** — 表示开始使用 Scanner 类。

```java
Scanner sc = new Scanner(System.in); // sc 是变量名，可以自定义
```

**步骤三：接收数据** — 真正开始读取输入。

```java
int i = sc.nextInt(); // 读取一个整数
String str = sc.next(); // 读取一个字符串
double d = sc.nextDouble(); // 读取一个双精度小数
String line = sc.nextLine(); // 读取一整行（包括空格）
```

> 注意：  
> 1. 导包动作必须出现在类定义的上边。  
> 2. `sc` 是变量名，可以自定义，但后面的 `new Scanner(System.in)` 格式固定不变。  
> 3. 读取字符串时，`next()` 遇到空格会停止，`nextLine()` 可以读取整行（包括空格）。

# 12 控制流程语句

## 12.1 分支语句

**if 语句**：

```java
if (条件) {
    // 条件成立时执行
}
```

**if-else 语句**：

```java
if (条件) {
    // 条件成立时执行
} else {
    // 条件不成立时执行
}
```

**if-else if-else 多分支语句**：

```java
if (条件1) {
    // 条件1成立时执行
} else if (条件2) {
    // 条件2成立时执行
} else {
    // 以上条件都不成立时执行
}
```

**switch 语句**：

```java
switch (表达式) {
    case 值1:
        // 执行代码
        break;
    case 值2:
        // 执行代码
        break;
    default:
        // 以上都不匹配时执行
        break;
}
```

> 注意：switch 表达式的值必须是整数、字符、字符串（Java 7+）或枚举类型。每个 case 分支末尾建议加 `break`，防止穿透。  

## 12.2 循环语句

**for 循环**：

```java
for (初始化; 条件判断; 更新) {
    // 循环体
}
```

**while 循环**：

```java
while (条件) {
    // 循环体
}
```

**do-while 循环**：

```java
do {
    // 循环体
} while (条件);
```

> 注意：for 循环和 while 循环先判断条件再执行，do-while 循环先执行一次再判断条件。  

# 13 数组

数组是相同类型数据的有序集合。  

## 13.1 数组的定义

```java
// 静态初始化
int[] arr = {1, 2, 3, 4, 5};

// 动态初始化
int[] arr = new int[5]; // 长度为 5 的整数数组，默认值为 0
```

## 13.2 数组的访问

```java
int[] arr = {10, 20, 30};
System.out.println(arr[0]); // 访问第 1 个元素，输出 10
System.out.println(arr.length); // 数组长度，输出 3
```

> 注意：数组索引从 0 开始，最大索引为 `length - 1`。访问超范围的索引会抛出 `ArrayIndexOutOfBoundsException`。  

# 14 方法

方法是完成特定功能的代码块。  

## 14.1 方法的定义

```java
修饰符 返回值类型 方法名(参数列表) {
    // 方法体
    return 返回值;
}
```

## 14.2 方法的调用

```java
public class Main {
    public static void main(String[] args) {
        int result = add(10, 20); // 调用方法
        System.out.println(result); // 输出 30
    }

    public static int add(int a, int b) {
        return a + b;
    }
}
```

> 注意：  
> 1. 方法必须先定义后调用。  
> 2. `static` 修饰的方法可以通过类名直接调用。  
> 3. 没有返回值的方法使用 `void` 作为返回值类型。  

# 15 IDEA 简介

IDEA（全称 IntelliJ IDEA）是用于 Java 语言开发的集成开发环境（IDE），由 JetBrains 公司开发，是业界公认的目前用于 Java 程序开发最好的工具之一。  

## 15.1 集成开发环境

集成开发环境把代码编写、编译、执行、调试等多种功能综合到一起，极大提高了开发效率。  

## 15.2 IDEA 项目结构

IDEA 中的项目结构层次如下：  

`Project`（项目） → `Module`（模块） → `Package`（包） → `Class`（类）  

- **Project**：一个完整的项目，包含多个模块。  
- **Module**：项目中的一个功能模块，可以独立编译。  
- **Package**：用于组织类的命名空间，类似文件夹。  
- **Class**：包含代码的类文件，是 Java 程序的基本组成单元。
