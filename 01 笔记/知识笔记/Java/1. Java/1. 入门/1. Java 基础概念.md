# 1.2 常用的 cmd 命令  
符号名称 + 冒号：盘符切换。例如 `E:`。
`dir`：查看当前路径下的内容。
`cd 目录`：进入单级目录。例如：cd itheima。
`cd ..` ：回退到上一级目录。
`cd 目录 1\目录 2\...` ：进入多级目录。例如：cd itheima\JavaSE。
`cd\`：回退到盘符目录。
`cls`：清屏。
`exit`：退出命令提示符窗口。
