# 1 人机交互-图形化界面的小故事
世界上第一个图形界面操作系统的开创者——施乐公司（Xerox）。  
1973 年，施乐帕洛阿尔托研究中心（Xerox PARC）研发出 Alto，这是世界上第一台使用图形用户界面（GUI）的计算机；苹果公司的 Lisa、Macintosh 以及微软公司的 Windows 均借鉴了施乐的设计思想。【补充】  
图形化界面的缺点：消耗内存，运行速度慢。  
Cmd：在 Windows 中，利用命令行的方式操作计算机。  
与图形化界面相比，命令行方式占用资源更少、运行速度更快。【补充】  

## 1.1 打开 cmd（Win + R）
按 `Win + R` 打开“运行”窗口，输入 `cmd` 后回车，即可打开命令提示符窗口。  
按 `Win + E` 打开“文件资源管理器”（Windows 10/11 中显示为“此电脑”，早期版本为“我的电脑”）。

# 2 Java 概述
Java 是一门面向对象的编程语言，1995 年由 Sun Microsystems 公司发布，2010 年 Sun 被 Oracle（甲骨文）公司收购。  
Java 之父：詹姆斯·高斯林（James Gosling）。  
名称由来：早期名为 Oak（橡树），后因商标冲突改名为 Java（取自印度尼西亚爪哇岛，也是咖啡的别称）。  
主流长期支持（LTS）版本：Java 8、Java 11、Java 17、Java 21。  

## 2.1 Java 三大平台
Java SE（标准版）：Java 的基础，用于桌面应用开发，是学习 Java 的起点。  
Java EE（企业版）：用于企业级应用开发，现已更名为 Jakarta EE。  
Java ME（微型版）：用于嵌入式及移动设备开发。  

## 2.2 Java 跨平台原理
Java 程序具有“一次编译，到处运行”的特点。  
流程：`.java` 源文件 → javac 编译 → `.class` 字节码文件 → JVM 解释执行。  
JVM（Java 虚拟机）屏蔽了底层操作系统的差异，Windows、macOS、Linux 各有对应版本的 JVM。  
注意：跨平台靠的是 JVM，Java 本身并不跨平台，不同平台需安装各自的 JVM。  

## 2.3 JDK、JRE、JVM 的关系
JVM：Java 虚拟机，负责运行字节码文件。  
JRE：Java 运行时环境 = JVM + 核心类库，只能运行 Java 程序，不能进行开发。  
JDK：Java 开发工具包 = JRE + 开发工具（javac、java、jar 等），开发人员安装 JDK。  
包含关系：JDK ⊃ JRE ⊃ JVM。  

# 3 Java 开发环境搭建
下载安装 JDK（建议使用 LTS 版本，如 JDK 8 或 JDK 17）。  
配置环境变量：  
JAVA_HOME：指向 JDK 的安装目录，例如 `C:\Program Files\Java\jdk-17`。  
Path：追加 `%JAVA_HOME%\bin`，使 `javac`、`java` 命令在任意目录下可用。  
验证：打开 cmd，输入 `java -version`，能输出版本信息即表示配置成功。  

# 4 第一个 Java 程序
创建 `HelloWorld.java` 文件，文件名必须与类名一致。  

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

编译：在 cmd 中执行 `javac HelloWorld.java`，生成 `HelloWorld.class` 文件。  
运行：执行 `java HelloWorld`，控制台输出 `Hello World`。  

# 5 Java 注释
单行注释：`// 注释内容`。  
多行注释：`/* 注释内容 */`。  
文档注释：`/** 注释内容 */`，可通过 javadoc 工具生成 API 文档。
