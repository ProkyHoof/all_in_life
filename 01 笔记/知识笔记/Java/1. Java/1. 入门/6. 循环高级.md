# 无限循环

**无限循环：循环一直停不下来。**  
for(;;){  
语句体；  
}  
while(true){  
语句体;  
}  
do{  
语句体;  
}while(true);
 
**注意事项：**无限循环的下面不能写其他代码了，因为循环永远停不下来，那么下面的代码永远执行不到。
 
# 跳转控制语句

在循环的过程中，跳到其他语句上执行。  
**continue:**跳过本次循环，继续执行下次循环。  
**break:**结束整个循环。
 
## 获取随机数

Java帮我们写好了一个类角Random，这个类就可以生成一个随机数。  
**导包** **--- Random****这个类在哪**  
import java.util.Random;  
导包这个动作必须出现在类定义的上边  
**创建对象** **---** **表示我要开始用****Random****这个类了**  
Random r = new Random();  
上面这个格式里面，只有r是变量名，可以变，其他的都不允许变  
**生成随机数** **---** **真正开始干活**  
int number = r.nextInt(随机数的范围);  
上面这个格式里面，只有number是变量名，可以变，其他的都不允许变
