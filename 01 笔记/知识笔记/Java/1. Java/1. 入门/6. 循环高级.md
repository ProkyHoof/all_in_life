# 1 无限循环
无限循环：循环一直停不下来。  

```java
for (; ; ) {
    语句体;
}

while (true) {
    语句体;
}

do {
    语句体;
} while (true);
```

注意事项：无限循环的下面不能写其他代码了，因为循环永远停不下来，那么下面的代码永远执行不到。  

# 2 跳转控制语句
在循环的过程中，跳到其他语句上执行。  
- `continue`：跳过本次循环，继续执行下次循环。  
- `break`：结束整个循环。  

# 3 获取随机数
Java 帮我们写好了一个类叫 Random，这个类就可以生成一个随机数。  

导包 —— Random 这个类在哪：  

```java
import java.util.Random;
```

导包这个动作必须出现在类定义的上边。  

创建对象 —— 表示我要开始用 Random 这个类了：  

```java
Random r = new Random();
```

上面这个格式里面，只有 r 是变量名，可以变，其他的都不允许变。  

生成随机数 —— 真正开始干活：  

```java
int number = r.nextInt(随机数的范围);
```

上面这个格式里面，只有 number 是变量名，可以变，其他的都不允许变。  
注意：`r.nextInt(10)` 生成的是 0 ~ 9 之间的随机数，包含 0，不包含 10。【补充】  
若要生成 1 ~ 100 之间的随机数，使用公式：`int number = r.nextInt(100) + 1;`【补充】
