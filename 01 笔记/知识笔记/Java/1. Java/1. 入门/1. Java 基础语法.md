# 1 注释
注释是在程序指定位置添加的说明性信息。  
简单理解，就是对代码的一种解释。  
注释分类：  
- 单行注释：`//注释信息`  
- 多行注释：`/*注释信息*/`  
- 文档注释：`/**注释信息**/`  

> 注意：  
> 注释内容不会参与编译和运行，仅仅对代码的解释说明。  
> 不管是单行注释还是多行注释，在书写的时候都不要嵌套。

# 4 制表符
`\t` 制表符：在打印的时候，把前面字符串的长度补齐到 8，或者 8 的整数倍。最少补 1 个空格，最多补 8 个空格。  
示例：  

```java
System.out.println("姓名\t年龄"); // 输出：姓名    年龄
```

# 5 null 空字符
null 表示空值，只能赋值给引用数据类型的变量。  
示例：  

```java
String s = null; // s 不指向任何对象
```

# 6 变量
变量的定义格式：  

```java
数据类型 变量名 = 数据值;
```

变量的使用方法：  
1. 输出打印  

```java
int a = 10;
System.out.println(a); // 10
```

2. 参加计算  

```java
int a = 10;
int b = 20;
System.out.println(a + b); // 30
```

3. 修改记录的值  

```java
int a = 10;
a = 20;
System.out.println(a); // 20
```

变量的注意事项：  
- 只能存一个值。  
- 变量名不允许重复定义。  
- 一条语句可以定义多个变量。  
- 变量在使用之前一定要进行赋值。  
- 变量的作用范围。  

# 7 计算机的存储规则
在计算机中，任意数据都是以二进制的形式来存储的。  
使用汉字编码表：GBK 编码和 Unicode 编码。  
图片数据：  
- 2K 屏（1920 * 1080 / 2048 * 1080 / 2048 * 858）  
- 4K 屏（3840 * 2160 / 4096 * 2160 / 4096 * 1716）  

黑白图：  
- 1 代表“白”，0 代表“黑”。  
- 灰度表：0 表示“黑”，255 表示“白”。

光学三原色：  
通过每一个像素点中的 RGB 原色来存储。  
红绿蓝，其中取值范围为（0~255）。  
声音数据：  
对声音的波形图进行采样再存储。

# 9 标识符
就是给类，方法，变量等起的名字。  
标识符命名规则（硬性要求）：  
- 由数字、字母、下划线（_）和美元符（$）组成。  
- 不能以数字开头。  
- 不能是关键字。  
- 区分大小写。  

标识符命名规则（软件建议）：  
- 小驼峰命名法：方法、变量  
  - 标识符是一个单词的时候，全部小写。如：`name`  
  - 标识符由多个单词组成的时候，第一个单词字母小写，其他单词首字母大写。如：`firstName`  
- 大驼峰命名法：类名  
  - 标识符是一个单词的时候，首字母大写。如：`Student`  
  - 标识符由多个单词组成的时候，每个单词的首字母大写。如：`GoodStudent`  

# 10 键盘录入
介绍：Java 帮我们写好了一个类叫 Scanner，这个类就可以接受键盘输入的数据。  
步骤一：导包——Scanner 这个类在哪。  

```java
import java.util.Scanner; // 导包的动作必须出现在类定义的上边
```

步骤二：创建对象——表示我要开始用 Scanner 这个类了。  

```java
Scanner sc = new Scanner(System.in); // 上边这个格式里面，只有 sc 是变量名，可以变，其他的都不允许变
```

步骤三：接收数据——真正开始干活了。  

```java
int i = sc.nextInt(); // 左边这个格式里面，只有 i 是变量名，可以变，其他的都不允许变
```
