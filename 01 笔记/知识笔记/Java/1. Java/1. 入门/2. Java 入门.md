# 1 Java 可以做什么
Java SE：Java 语言的（标准版），用于桌面应用的开发，是其他两个版本的基础。  
桌面应用：用户只要打开程序，程序的界面会让用户在最短的时间内找到他们需要的功能，同时主动带领用户完成他们的工作并得到最好的体验。  
Java ME：Java 语言的（小型版），用于嵌入式电子设备或者小型移动设备，被淘汰了。  
Java EE：Java 语言的（企业版），用于 Web 方向的网站开发。在这个领域，是当之无愧的第一。  
网站开发：浏览器 + 服务器。  
应用：桌面应用开发、企业级应用开发、移动应用开发、科学计算、大数据开发、游戏开发。

# 3 高级语言的编译运行方式
## 3.1 编程、编译、运行
编程：Java 程序员写的 .java 代码，C 程序员写的 .c 代码，python 程序员写的 .py 代码。  
编译：机械只认识 0011 的机械语言，把 .java .c .py 代码做转化让机械认识的过程。  
运行：让机械执行编译后的指令。  
## 3.2 编译的类型
- 编译型（C/C++）：整体编译，出现编译文件 .obj。  
- 解释型（Python）：按行编译，不会出现编译文件，直接将源代码进行运行。  
- 混合型（Java）：出现编译文件 .class。不是直接运行在系统中的，而是运行在虚拟机中的。  
## 3.3 跨平台原理
Java 语言的跨平台是通过虚拟机实现的。  
Java 语言不是直接运行在操作系统里面的，而是运行在虚拟机中的。  
针对于不同的操作系统，安装不同的虚拟机就可以了。  
## 3.4 JRE 和 JDK
JVM（Java Virtual Machine）：Java 虚拟机，真正运行 Java 程序的地方。  
核心类库：Java 本身提供的库。  
开发工具：javac 编译工具，java 运行工具，jdb 调试工具，jhat 内存分析工具等。  
JDK（Java Development Kit）：Java 开发工具包。包括 JVM、核心类库、开发工具，JDK 中包含了 JRE。  
JRE（Java Runtime Environment）：Java 的运行环境。包括 JVM、核心类库、运行工具。  
> 注意：  
> JDK 包含 JRE，JRE 包含 JVM。用户只需要安装 JDK 即可运行和开发 Java 程序。
