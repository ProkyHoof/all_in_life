本人因为自驱力不够，所以给自己一个实质性的反馈才能继续做事，于是在 2026 年 7 月 2 日创建了 all_in_life。这是一个关于人生的项目，我需每天去修改它，去打磨它，去完善它，因为它就是我自己哈...
# 1 简介
all_in_life 是一个关于 ProkyHoof （你们也可以叫我猪脚 doge）日常记录的个人笔记，主要就是像全身心投入到自己的注意力上，好了，话不多说，那就开始介绍吧。里面包含了四个模块：  
1. 仪表盘：主要记录所有笔记的更改状态。
2. 笔记：
	1. 路线图笔记：路线图笔记主要是记录某一个人生阶段要做的事情吧，这个事情很大，我需要分阶段去完成它，它就能需要成吨的知识和项目组成，我的理解更是一个人生阶段性的总结吧。
	2. 项目笔记：就是理论知识的落地部分吧，都是独立参与的作品，可以有些后面会发现当初的自己还是很好玩的。
	3. 知识笔记：顾名思义了，就是理论知识，干货满满哈。
	4. 资源笔记：可能是一些零碎的知识点，可能是宝贵的资源网站，也可以是一些软件的个人设置，好用的插件和软件都再推荐列表中哈。
3. 模板：就是笔记模板，没啥东西。
4. 附件：一些实体资料。
